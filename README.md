# A-POS System

A relatively complete POS (Point of Sale) system, and my first project uploaded to GitHub.

## About

This is a POS system built with C++ and Qt. It covers multiple modules including cashier checkout, product management, VIP, data encryption, and auto-update.
The project is still being improved. **No release version is provided — this repository is for source code sharing and feedback only.**

## Features

1. Startup animation
2. Login and registration (Hash-Salt verification logic; server-side code not disclosed)
3. Auto-login
4. Add products
5. Cashier checkout
6. Order records
7. Product inventory system
8. VIP system
9. Single-instance protection
10. System tray
11. System settings
12. File extension association and reading
13. Cash register scanner adaptation
14. Printer adaptation
15. AES-256 file encryption
16. Code obfuscation (to prevent partial decompilation)
17. Automatic update detection and auto-update
18. Server disconnection detection
19. XOR encryption
20. Resumable transfer
21. Upload backup transfer
22. Launch on startup
23. Server communication
24. User file isolation
25. File integrity check

## Tech Stack

- **IDE / Tools**: Qt, Visual Studio
- **Language**: C++ (primary)
- **Framework**: Qt
- **Database**: SQLite, custom database
